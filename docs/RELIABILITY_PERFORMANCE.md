# golf.7／通用版：热点、按键与流畅度

本次从已交付golf.6修改。保持H.264／30帧和现有Siri／麦克风路径，删除的厂商仪表、HUD、ADB功能仍未恢复。新版尚未在实车验证；下面分别说明代码变化与目前证据。

## 热点恢复

10月6日的报告内有两次“热点已开启，但找不到本地AP接口”，等待60秒超时，手动关闭再开启后ap0出现。新版“启动与语音”增加默认开启的独立选项“热点异常自动恢复（旧系统）”。仅Android4.2–5.1、系统热点已开启或失败、保存SSID匹配、接口持续缺失5秒且连接剩余时间充足时，后台请求关闭再开启一次，使用系统原热点配置。

系统明确关闭、未知状态、正在启停、SSID不符、已有健康接口或用户取消时不启动恢复。启动过渡结束后重新等待5秒。应用自动重试共用一次预算，直到发现正常接口或用户手动再次开始连接；不会每次重连都开关热点。若已请求关闭，取消或异常时仍尝试恢复开启。请求被系统接受只表示请求成功，真正恢复以AP接口出现为准。固件拒绝隐藏接口时保留手动系统设置入口。

这修复了报告中已观察到的接口缺失路径。已存在接口但DHCP、无线驱动或iPhone加入失败是另外的情况，不能在本机判定全部修好。首次使用仍需用户开启系统热点并填写其名称、密码。

## 实体按键学习

报告里收到239／563和236／560等非标准信号，但无法知道分别属于哪个实体按钮。原生蓝牙电话、播放器可用只说明原生程序能收到自己的输入，不能证明第三方应用收到同样信号。

首页“方向盘按键学习”分别选择上一首、下一首、电话或语音，按对应实体键，看到按键码／扫描码后点击“保存此键”。不自动猜测映射，未点击保存不改动设置；返回、电源、首页、音量、导航和字符键保留原用途。同一信号不能分配给两个功能，可清除全部学习记录。学习和检测期间应用不发送音乐或电话控制。

保存后回到投屏验证。上一首／下一首只在首次按下发送一次；电话键短按释放请求接听，至少800ms长按释放请求挂断；独立ENDCALL请求挂断。语音键保留Siri。窗口、媒体广播、媒体会话共享去重。接听／挂断仍需iPhone实际执行验证；本地入队或加密消息写出不是手机确认。

若学习页面始终没有信号，不能保存映射。请导出故障报告，并说明各按钮是否无信号、是否打开原生界面。导出时追加最多16个输入设备的编号／来源类型和每个系统键布局目录最多16个文件名，不导出设备个人名称，不读取字符内容、后台轮询或修改布局。此版没有未知厂商MCU／CAN协议桥接。

## 视频路径

12:34两份报告包含同一12:30:36会话，去重后统计有19次恢复，全部来自旧250ms积压阈值；该会话没有队列溢出、输入停滞或解码异常日志。用户确认清晰档基本流畅，当前实际视频1024×600／30帧。由此针对短暂积压修正，而不是认定硬件无法解码原生分辨率。

队列使用锁内帧数／字节数计数，减少逐帧遍历、临时列表和队列节点分配，保留帧／字节上限以及配置、Surface和Resync顺序。复用视频BufferInfo，缓存API17输入缓冲区；解码器重建时清空缓存。已有原地AnnexB转换继续保留，并补上畸形长度整数溢出保护。

短积压先解码追赶，输入参考帧不直接丢弃。只有已经解码且确认后续更近画面已就绪时，才跳过超过250ms的旧输出；每轮最后输出继续显示。驱动修改时间戳、输出乱序或无法关联时保守显示。输入积压超过750ms、真实丢参考帧、容量溢出或解码错误仍重建并请求关键帧，不无限堆积。统计追加decodeOnly，指解码完成但为追赶跳过显示的帧。

新连接重新读取保存的画质和热点，修复保留Host可能沿用上一连接比例的问题。首页显示约计尺寸，实际画布、视频尺寸以当前会话报告为准。

本机队列微基准只比较Java队列操作与分配，不代表车机帧率、CPU占用或肉眼流畅。不能保证所有无线环境、旧面板响应和固件都无可见卡顿。实际效果需要用同画质、同手机、相近场景的新报告比较。

## 通用版

Golf版包名com.legacy.golfwireless，版本0.2.7-golf.7／107，可同签名覆盖旧版。通用版包名com.legacy.headunitwireless，版本0.2.7-universal.1／107，名称“车机无线CarPlay”，独立保存连接、身份、画质和按键设置，可与Golf版共存；同一车机一次只运行一个连接。

两版共用相同连接、视频、音频和学习实现。均衡为可用画布80%，流畅60%，清晰100%，全部30帧；尺寸跟随各车机实际投屏区域，未固定1024×600。API17是最低安装版本；其它固件还需具备可用热点、蓝牙RFCOMM及H.264解码能力。未连接实车的机型不能仅凭安卓版本宣称兼容。

## 验收顺序

先覆盖Golf版，保留已确认基本流畅的清晰档。开启热点异常恢复，验证无需手动关闭再开启；再逐键学习并在iPhone播放／通话中确认执行。随后测地图移动、滑动、音乐、导航提示、Siri、电话和至少三次断开重连，导出新报告。最后在其它车机安装通用版单独配置并重复检测。

新包构建、自动测试、API17兼容检查、签名、源码与U盘校验记录见VALIDATION.md及随包验证结果.json。上述实车结果仍待用户反馈。
