# golf.5：可选自启动、自动连接与麦克风

按用户提出的可选功能范围，使用writing-plans/executing-plans流程在现有独立适配源码中执行。底版仍是Legacy0.2.7；研究主线0.2.12的新功能，但不引入比亚迪车辆接口或主线整体迁移。

## 设计与边界

三个独立开关默认关闭：“开机打开应用”“打开应用后自动连接”“Siri／麦克风（实验）”。开机选项只打开普通首页；自动连接在保存配置、手机已配对、蓝牙和热点就绪后，才启动既有连接流程。等待上限90秒，每2秒检查一次；暂停首页时取消调度，手动停止后本次首页不再自动发起，不循环重启服务。热点继续由车机系统开启，不修改系统或使用ADB。开机广播能否发给应用、车机是否仅休眠，需要实车确认。

语音处理在iPhone侧。本端只在手机请求通话或语音识别音频流时采集并传送；没有常驻录音、文件录音或本地识别模型。API17使用PCM输入，避免宣告旧系统没有的Opus编码／解码能力；格式限制只随麦克风启用影响旧系统语音协商，关闭时保留原广告。录音权限按系统版本处理，权限拒绝则按无麦克风继续投屏。纠正麦克风套接字无条件IPv6绑定，和现有IPv4热点路径一致。录音源失败时有限回退到普通MIC，仍失败停止语音、记录原因，不破坏视频。空读不忙循环；只记录计数/电平和状态，不保存音频内容。

性能结论不得伪造：自启与自动连接不增加稳态视频解码任务；麦克风会增加采集、封包和无线上传，通常比视频负担小，但此车机的实际CPU、麦克风接线、静音、回声和流畅度尚未测量。使用时分别实测，不默认开启。
