# Installation

中文安装步骤、SHA-256 校验值及 APK 中实验性认证材料的公开披露见项目根目录的 [`安装说明.md`](../安装说明.md)。

English: Android 4.2 (API 17) or later is required. Download `HeadUnitWireless-CarPlay-0.2.7-universal.1.apk` from the GitHub Release, transfer it to the head unit, allow the file manager to install unknown apps, and open the APK to install. Pair the iPhone in Android settings and enable the head unit's Wi-Fi hotspot. In the app, enter the hotspot name and password, select the phone, and start the connection. Compatibility depends on the head unit firmware's hotspot, Bluetooth RFCOMM, and H.264 support. The APK contains extractable experimental accessory-authentication material; see `THIRD_PARTY_NOTICES.md`.
