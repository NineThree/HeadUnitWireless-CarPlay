# golf.7与通用版实施计划

**目标：** 修复已观察到的旧系统热点接口缺失，增加明确的OEM按键学习，降低解码积压造成的重建与分配，并交付两个Android4.2/API17起的独立安装包。全部保持H.264/30帧和现有Siri、麦克风路径。

**基线：** 已交付golf.6源码ZIP，当前HEAD是改造前上游，不能当本次差异基线。保留原版和所有个人报告；不提交、推送或卸载现有应用。

**证据：** 12:23与12:36两次接口等待60秒失败，手动重启后ap0出现；12:30:36同一会话在两份导出中重复，只统计一次。原生1024×600成功；该会话有多次超过250ms积压导致解码器重建。收到239/563、236/560等OEM码，未证实对应按钮；不自动猜测映射。

## 热点恢复

- [x] 回归CarHotspotStatus对开启、关闭、过渡和失败状态的区别；过渡/失败不能当作明确关闭。
- [x] 独立LegacyHotspotRecovery只在API17–22、恢复选项开启、已保存SSID与系统配置一致且接口持续缺失时尝试一次。健康热点不重启；明确关闭、未知状态或配置不匹配不启用。
- [x] 使用旧系统setWifiApEnabled保留系统当前配置，等待关闭再恢复；取消与异常后恢复由应用关闭的热点。超时、拒绝和不支持返回诊断结果，不声明成功。
- [x] 接入ManualHotspotManager等待循环，在后台执行；Controller及自动连接允许可恢复的过渡/失败状态，默认不代替用户开启明确关闭的热点。开关独立保存。
- [x] 假热点端口重放接口缺失→关闭/开启→恢复，覆盖拒绝、取消、未知、较新系统、SSID不符、有限等待和健康接口。

## 按键学习

- [x] 保留标准切歌、Siri、CALL/ENDCALL；新GolfKeyBindings仅保存用户明确学习的keyCode+scanCode，不猜239/236。
- [x] 首页逐键学习上一首、下一首、电话、语音；候选需点击保存，禁止返回/电源/首页/音量/普通字符，拒绝相同信号分配给不同用途，可清除。
- [x] 窗口/广播/媒体会话共用映射与去重，短/长电话键仍按真实释放时间；检测期间不发送控制指令。保留收到/未收到信号的区别。
- [x] 真实加密HID回归学习后的OEM码；导出映射与有限输入设备/键布局诊断。不恢复未知厂商MCU或猜广播协议。
